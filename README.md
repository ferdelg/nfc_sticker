# NFC Sticker

Page that opens when you tap Ferdy's NFC sticker.

**Live URL:** https://ferdelg.github.io/nfc_sticker/

## How to write the sticker

1. Open the **NFC Tools** app.
2. Tap **Write** → **Add a record** → **URL**.
3. Paste the link: `https://ferdelg.github.io/nfc_sticker/`
4. Tap **Write**, then hold the sticker to the top of the iPhone.

> ⚠️ Never use **"Lock tag"**. It's permanent and the sticker can't be rewritten afterwards.
